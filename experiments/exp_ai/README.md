# exp_ai

0.88付近の上位スコアとの差について、特徴量追加の効果を同一のLightGBM・
リーク防止nested CVで比較する実験系列です。exp01～exp06は累積追加、exp07～
exp10はv2へ一つの特徴量ブロックだけを足す独立実験です。

## 共通評価

- outer: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`
- inner: `StratifiedKFold(n_splits=4)`
- 閾値: outer学習部分のinner OOF F1だけで選択
- モデル: LightGBM（500 trees、learning rate 0.03、depth 3、7 leaves）
- 出力: 各実験の`feature_importance.png`と`f1_scores.png`のみ

## 追加前の診断

- 上場種別のtrain分布はPR 536件（72.24%）、ST 192件（25.88%）、GR 14件
  （1.89%）。testはPR 585件（73.12%）、ST 204件（25.50%）、GR 11件
  （1.38%）だった。exp07は学習fold内で5%未満を「その他」に統合した。
- v2参照元をコードで照合し、exp08は未使用財務項目を主成分とする9列、exp09は
  v2最終出力に含まれないアンケート3・6・10の3列だけを追加した。
- DX展望の名詞・動詞TF-IDFをouter学習foldだけで30成分まで診断した平均累積
  寄与率は、10成分9.3193%、20成分13.6649%、30成分17.3769%。20成分で
  先頭30成分が説明する分散の78.64%を保持するため、exp10は20成分とした。
- exp11では3成分4.8577%、5成分6.5372%の累積寄与率とexp10の重要度を踏まえ、
  5成分を採用した。それでもnested OOF F1は0.7363で改善しなかった。
- 30成分SVDの軸推定条件を固定して単独比較したところ、第1成分は0.6721、
  第3成分は0.7158で、第2成分だけのexp01（0.7634）を下回った。
- 企業概要・組織図の追加計算は今回のバッチでは実施せず、既存exp06の結果だけを
  履歴として残した。

## 結論

- 独立追加では`exp09`が0.7744で最高となり、未使用アンケート3列は次のモデル・
  パラメータ探索へ残す価値がある。ただし0.88との差は0.1056あり、特徴量3列だけで
  埋まる規模ではない。
- 上場種別は偏っているが希少カテゴリがGRの1種類だけなので、「その他」への名称
  変更ではOne-Hotの自由度が減らず、改善しなかった。
- 未使用財務9列とDX展望SVD 20成分・5成分は悪化した。SVD成分をさらに調整する
  優先度は低い。次はexp09を基準にLightGBMのパラメータ探索を行い、その後に
  異種モデルとのアンサンブルを評価するのが妥当。
- SVD単独成分では第2成分が明確に最良だった。第1・第3成分への置換や複数成分化
  は採用せず、現行の第2成分だけを維持する。
