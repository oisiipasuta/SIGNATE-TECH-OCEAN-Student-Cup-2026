# `exp_tree_of_corp` 組織図特徴量実験

## 結論

汎用組織図特徴を`all_features_v3`へ追加した`exp02`が最良で、nested OOF F1は
0.7989だった。既存`all_features_v3`の0.7744から+0.0245改善した。
`DX推進室完全一致フラグ`をさらに加えた`exp03`は0.7944となり、`exp02`から
0.0045低下したため、完全一致語には依存せず汎用特徴を採用する。

追加アブレーションでは、正規化7特徴の`exp04`は0.7606、デジタル組織数だけの
`exp05`は0.7718で、v3単体を上回らなかった。DX推進室完全一致だけの`exp06`は
0.7922まで改善したが、汎用15特徴を組み合わせる`exp02`が引き続き最良だった。
指定した構造・デジタル体制6特徴を加えた`exp07`は0.7792で、v3から+0.0048の
小幅改善に留まり、`exp02`には届かなかった。
追加6特徴内では、デジタル組織比率のouter平均split importanceが71.2で最大となり、
デジタル組織数単体の12.4を上回った。ただし、重要度は方向や因果を示さず、
CVの改善幅も小さいため補助特徴として扱う。

## 実データ分析

train 742社、test 800社の組織図に欠損はなかった。最終パーサーではtrainの
684社（92.2%）、testの750社（93.8%）を縦型ツリーとして階層解析できた。
横型・自由記述形式では深さ・分岐・配置を欠損にし、誤推定値をモデルへ渡さない。

目的変数との相関上位は次のとおり。Pearson/Spearman相関は関連の強さであり、
方向性や因果効果を示さない。

| 特徴量 | Pearson | Spearman | test SMD |
| --- | ---: | ---: | ---: |
| デジタル組織数 | 0.1767 | 0.1562 | -0.0271 |
| デジタル組織比率 | 0.1696 | 0.1405 | 0.0067 |
| DX変革組織有無 | 0.1503 | 0.1503 | 0.0743 |
| DX推進室完全一致フラグ | 0.1486 | 0.1486 | 0.0849 |
| 研究開発組織数 | 0.0948 | 0.0878 | 0.0220 |
| 調達・購買組織数 | -0.0869 | -0.0868 | -0.0024 |
| デジタル組織経営直下フラグ | 0.0834 | 0.0834 | 0.0679 |

`DX変革組織有無`の購入率は、なし18.1%、あり30.9%だった。一方、ノード数、
最大階層、第一階層組織数、平均分岐数などの構造特徴は、いずれも目的変数との
絶対相関が0.05程度以下だった。上位特徴のtrain/test SMDは0.1未満で、大きな
分布差は観測されなかった。

`DX変革組織有無`と`DX推進室完全一致フラグ`の特徴間相関は0.9919である。
exp02へ完全一致フラグを重ねたexp03ではCV性能が低下したため、汎用特徴セットへ
完全一致フラグをさらに追加する必要はないと判断した。

デジタル組織比率は`デジタル組織数÷組織ノード数`で、trainの欠損率0.4%、
testの欠損率0.25%だった。目的変数とのPearson相関0.1696を維持しながらtest SMDは
0.0067と安定していたが、他の正規化比率とまとめたexp04では予測性能が低下した。

## 実験結果

| ID | 特徴量 | 生成列数 | nested OOF F1 | 最終閾値 | 基準との差 |
| --- | --- | ---: | ---: | ---: | ---: |
| baseline | all_features_v3 | 23 | 0.7744 | 0.3260 | - |
| exp01 | 汎用組織図特徴のみ | 15 | 0.4059 | 0.1390 | - |
| exp02 | all_features_v3＋汎用組織図特徴 | 38 | **0.7989** | 0.2770 | +0.0245 |
| exp03 | exp02＋DX推進室完全一致 | 39 | 0.7944 | 0.3320 | +0.0200 |
| exp04 | all_features_v3＋正規化7特徴 | 30 | 0.7606 | 0.2890 | -0.0138 |
| exp05 | all_features_v3＋デジタル組織数 | 24 | 0.7718 | 0.3350 | -0.0026 |
| exp06 | all_features_v3＋DX推進室完全一致 | 24 | 0.7922 | 0.3200 | +0.0178 |
| exp07 | all_features_v3＋選択組織図6特徴 | 29 | 0.7792 | 0.2570 | +0.0048 |

全実験はouter 5-fold、inner 4-fold、seed 42で評価した。分類閾値は各outer学習
部分のinner OOF予測だけから選び、outer validationを閾値選択には使用していない。
